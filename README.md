# DAHP - Dynamic Adaptive Hallucination Prevention

A research-oriented framework for reducing hallucinations in Large Language Models through adaptive multi-perspective reasoning.

## Current Features

- ✅ Risk Prediction
- ✅ Dynamic Perspective Allocation
- ✅ Multi-Perspective Response Generation
- ✅ Semantic Confidence Estimation
- ✅ Confidence-based Decision Engine

## Tech Stack

- Python
- Google Gemini API
- SentenceTransformers
- scikit-learn
